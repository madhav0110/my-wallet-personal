# Mobile Wallet Passbook

A React and TypeScript mobile wallet demo built with Vite, Tailwind CSS, and Lucide icons.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Getting started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the development server.
- `npm run build` type-checks the app and creates a production build in `dist/`.
- `npm run preview` serves the production build locally.

Wallet data is stored in the browser's local storage. The included card and transaction details are demo data only; do not enter real card credentials.
